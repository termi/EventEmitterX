## Technical Details

  capture-rejection hook; enumerate symbol keys; expose once callback identity; add `IEventTiming`.
  `eventsAsyncIterator.ts` uses a local capability type without changing iteration behavior.
- `spec/modules/events_spec.ts`: explicitly inject Node User Timing into five ServerTiming instances.
  This repairs twelve missing `performance.mark` failures and two deferred error cascades caused by failed setup.
  Type the reusable suite's constructor argument instead of reading an untyped `arguments[0]`.
- Add twelve native Node differential tests, two separate DOM tests and emitter type-contract fixtures.
  Assertions cover selected ordering, listener identity, symbols, cleanup, rejection hooks and timing behavior.
- `_dev/check_signal_types.cjs` rejects every diagnostic and checks emitted-declaration consumers with
  `skipLibCheck: false`; remove the 36-diagnostic allowlist after fixing its causes.
- Add a compiler-API build driver and copy authored library `.d.ts` inputs into both outputs.
  Sequential and parallel builds use this driver. TypeScript emission alone omitted these authored inputs.
- Add actual build declaration checks and CJS runtime smoke, plus the fail-fast `pnpm verify` pipeline.
  Existing `typecheck:signals` remains available alongside `typecheck:contracts`.
- AI reasoning: local metadata types preserve closed consumer contracts; explicit timing capabilities avoid
  replacing global browser performance. Build checks validate delivered declaration files rather than only sources.
  Alternatives and limitations are documented in the reason files.
