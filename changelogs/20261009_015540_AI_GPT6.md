## Human-Readable Summary

Proxy listeners now keep receiving events after a transient once listener fires. Selective and bulk cleanup remove
only their owned source bridges, including symbols, empty strings and equivalent numeric/string keys.
A target exception no longer leaves a proxy stuck in anti-loop state. Changed source hooks are cleaned through
recorded subscription ownership rather than being recomputed.

Error monitors observe before an unhandled error throws and their listener mutations take effect. Async once
callbacks reach captureRejections; rejection hooks receive emitter context. Abort subscriptions use native protected
Node delivery where available and an explicitly limited once-only browser fallback. Pre-aborted subscriptions now deliver asynchronously.

## Technical Details

- `EventEmitterSimpleProxy.ts`: persistent group bridges, symbol-safe enumeration, explicit undefined selection and numeric-key comparisons.
- `EventEmitterProxy.ts`: persistent bridges, equivalent-key lookup/removal, symbol counter cleanup and finally-based anti-loop restoration.
- `EventEmitterX.ts`: monitor delivery before current error-handler selection; symbol lifecycle removal and absent-group guards;
  once result return, hook context and capability-aware abort helper.
- Register 28 proxy ownership/routing tests in the separate proxy specifications, using a shared `spec_utils/proxySubscriptionOwnership.ts` contract; replace six old proxy todo placeholders with executable coverage.
  Add 18 Node and five DOM cases; update old error-monitor assertions that encoded the former behavior.
- Extend positive/negative generic proxy fixtures in both source and emitted-declaration consumers.
- Update consumer compatibility/migration, proxy examples, verification results and roadmap in English/Russian.
- AI reasoning: bridges belong to listener groups, whereas local wrappers own once semantics. Cleanup follows recorded
  callback/source identity. Native abort protection cannot be faithfully reconstructed through ordinary browser events.
  Alternatives and limitations are recorded per problem in the linked reasons.

## [RU] Понятное описание изменений

Proxy-слушатели продолжают получать события после срабатывания временного once-слушателя. Выборочная и общая очистка снимают
только принадлежащие им source bridges, включая символы, пустые строки и эквивалентные numeric/string ключи.

записанное владение подписками вместо повторного вычисления.

Error monitors наблюдают до исключения необработанной ошибки, изменения слушателей монитором учитываются. Async once
callbacks достигают captureRejections; rejection hooks получают контекст emitter. Abort-подписки используют нативную защищённую
доставку Node при наличии и явно ограниченный одноразовый браузерный fallback. Pre-aborted подписки теперь доставляются асинхронно.
