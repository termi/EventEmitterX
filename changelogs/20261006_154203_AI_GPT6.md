## Human-Readable Summary

Consecutive computed reducers now receive intermediate output from preceding
writes. Three increments in the trigger scenario produce 4 without the temporary
arithmetic workaround. Plain source writes remain lazy, while computed reducer
previews do not publish values or release throttles. Async reducers wait for
pending output; disposal and abort cancel outstanding writes.
Known async reads keep Promise.resolve(lastValue) after disposal, including
native async functions disposed before evaluation and pending previews.

Constructor and factory inference support async/hybrid results and contextual
data. Readers, listeners, mutations, projections and generated methods now use
the same source/output model. A strict signal-contract command checks source and
emitted declarations without concealing the existing library diagnostics.

## Technical Details

- EventSignal.ts adds a private intermediate-output cache and per-instance write
  queue. Source/dependency epochs invalidate previews; successful publication
  compares against the previously published value. Counts represent actual
  computations, including previews.
- New Promise-read, initial-value, computation-mode, projection and cached-output
  booleans are stored in StateFlags bits 22–26 instead of separate properties.
  Constructor flags accumulate locally before initialization; computation/cache
  transitions set or clear their bits without changing existing flag values.
- Queued set/createMethod return Promise completion for applied source writes.
  A batch fails on preview/in-flight computation/reducer errors. Promise-returning
  reducers are rejected. Synchronous mutate rejects during pending writes rather
  than bypassing their order. New weak continuations and destruction guards
  prevent late work from resurrecting disposed signals.
- Preserve T/S/D/R positions, default source to Awaited<T>, separate initial and
  raw computation result, and infer callbacks with the complete EventSignal self.
  Its conservative result mode avoids recursive inference while retaining every
  method, including markNextValueAsForced. Compatibility overloads support a
  precisely annotated self result mode. Compile fixtures cover the existing
  object-returning example, the full self API and invalid self writes. Different
  initial/output domains require an explicit union; get honestly includes sync
  fallback and async result. Promise initial values include undefined in last
  snapshots, listener payloads and React types.
- Map awaits resolved output, starts undefined and is a read-only one-way
  projection in types and runtime. Mutate rejects foreign keys and wrong values.
  Source comparison distinguishes null from absent undefined.
- Existing EventSignal_spec regressions now assert ordered intermediate output.
  Async read assertions narrow the union with instanceof before accessing then;
  they still assert that get itself returns Promise. Remove false initial-Promise
  casts and read the actual asyncComputed7/8 values instead of reusing asyncComputed5.
  Direct writes preserve the separate latest-write async race test. Added 22
  controlled-Promise/runtime cases with using/disposal and strict compile fixtures.
- package.json adds typecheck:signals; tsconfig.signal-types.json and
  _dev/check_signal_types.cjs check exact positive/negative source assertions and
  emitted declarations under CommonJS, NodeNext and Bundler. An explicit JSON
  ledger retains the 36 known diagnostics; changes to that baseline fail the check.
  Emission is isolated to ignored build_cache; declaration consumers use skipLibCheck.
- ReadResult normalizes Promise payloads to the output domain, including last-value
  fallback after no-update/error. New fixtures cover direct-then rejection,
  narrowing and Promise.resolve normalization. Async disposal preserves Promise
  reads; native async detection does not force computation, observed regular async
  results/previews preserve their mode and synchronous signals retain direct reads.
  The remaining Promise-only static contract needs a declared runtime mode for
  ordinary Promise-returning functions before their first invocation.
- Roadmap 03.1/03.2 records implemented core and remaining acceptance. EN/RU
  contract documents explain non-obvious choices, alternatives and migration.

AI reasoning: computed reducers that consume output cannot satisfy the required
sequence while always reading stale output. Private previews give them the needed
value without public get calls or premature notification. Separating contextual
self result mode breaks recursive inference; a restricted Pick, unconstrained any and a wholesale generic
redesign were rejected. Existing emitter failures and global retention remain
separate work rather than expanding this change into dependencies or lifecycle
redesign.

The runtime test comments link to roadmap 03.1.1 and explain the workaround and
its remaining inline-inference limitation.
The reported nested-method data inference regression is mitigated by extracting
its data object before construction, preserving inferred method arguments without
casts or explicit generics. Obsolete TypeScript suppressions were removed from
the runtime case. Strict fixtures cover constructor/factory data and full-self
method access, including invalid arguments. The inline form remains unsupported
in this case; roadmap 03.1.1 records the reproduction, alternatives and deferred
signature work rather than claiming a general inference fix.

предыдущих записей. Три инкремента в trigger-сценарии дают 4 без временного

Async reducers ожидают pending output; disposal и abort отменяют ожидающие записи.
Известные async reads сохраняют Promise.resolve(lastValue) после disposal, включая

Вывод constructor и factory поддерживает async/hybrid results и контекстные
данные. Readers, listeners, mutations, projections и созданные методы используют
одну модель source/output. Строгая команда проверки контракта проверяет source
и сгенерированные декларации, не скрывая существующие diagnostics библиотеки.

## [RU] Технические детали

- EventSignal.ts добавляет приватный кеш промежуточного output и очередь записей
  экземпляра. Epochs source/зависимостей инвалидируют previews; успешная публикация
  сравнивает результат с предыдущим опубликованным значением. Счётчики отражают
  реальные computations, включая previews.
- Новые boolean-признаки Promise-чтения, начального значения, режима computation,
  проекции и кешированного output хранятся в битах 22–26 StateFlags вместо отдельных
  свойств. Флаги конструктора накапливаются локально до инициализации; переходы
  computation/кеша устанавливают или сбрасывают биты без изменения существующих значений флагов.
- Ожидающие set/createMethod возвращают Promise завершения применения source.
  Batch завершается ошибкой при ошибках preview/выполняющейся computation/reducer.
  Promise-returning reducers отклоняются. Синхронный mutate отклоняется во время
  ожидающих записей вместо обхода порядка. Новые слабые continuations и проверки
  уничтожения не позволяют поздней работе восстановить уничтоженный сигнал.
- Сохранены позиции T/S/D/R, source по умолчанию — Awaited<T>; разделены initial
  и raw computation result; callbacks выводятся с полным EventSignal self.
  Его консервативный режим результата устраняет рекурсивный вывод, сохраняя все
  методы, включая markNextValueAsForced. Совместимые перегрузки поддерживают
  точно аннотированный режим результата self. Compile fixtures проверяют
  существующий object-returning пример, полный API self и некорректные записи через self.
  Разные initial/output domains требуют явного union; get корректно включает
  sync fallback и async result. Начальный Promise добавляет undefined в last
  snapshots, listener payloads и React types.
- Map ожидает разрешённый output, начинает с undefined и является односторонней
  read-only проекцией в типах и runtime. Mutate отклоняет чужие ключи и неверные
  значения. Сравнение source отличает null от отсутствующего undefined.
- Существующие регрессии EventSignal_spec проверяют порядок промежуточного output.
  Async read assertions сужают union через instanceof перед доступом к then;
  они сохраняют проверку, что сам get возвращает Promise. Удалены ложные initial-Promise
  casts; читаются реальные asyncComputed7/8 вместо повторного asyncComputed5.
  Прямые записи сохраняют отдельный async race test последней записи. Добавлены
  22 runtime-сценариев с управляемыми Promise, using/disposal и строгие compile fixtures.
- package.json добавляет typecheck:signals; tsconfig.signal-types.json и
  _dev/check_signal_types.cjs проверяют точные положительные/отрицательные source
  assertions и сгенерированные декларации с CommonJS, NodeNext и Bundler. Явный
  JSON-реестр сохраняет 36 известных diagnostics; изменение базы ломает проверку.
  Генерация изолирована в игнорируемом build_cache; потребители деклараций используют skipLibCheck.
- ReadResult нормализует payload Promise до домена output, включая last-value
  fallback после no-update/error. Новые fixtures проверяют отклонение прямого then,
  сужение и нормализацию Promise.resolve. Async disposal сохраняет Promise-чтение;
  определение native async не запускает computation, наблюдавшиеся обычные async
  results/previews сохраняют режим, синхронные сигналы сохраняют прямое чтение.
  Оставшийся Promise-only статический контракт требует объявленного runtime-режима
  для обычных Promise-returning functions до их первого вызова.
- Roadmap 03.1/03.2 фиксирует реализованную основу и оставшиеся критерии.
  EN/RU-контракт описывает неочевидные решения, альтернативы и миграцию.

Обоснование AI: computed reducers, потребляющие output, не могут выполнить
требуемую последовательность при постоянном чтении устаревшего output. Приватные
previews предоставляют нужное значение без публичного get и ранних уведомлений.
Отдельный режим результата контекстного self разрывает рекурсивный вывод; ограниченный Pick, неограниченный any и
полная замена generics отвергнуты. Существующие emitter failures и глобальное
удержание оставлены отдельной работой вместо расширения изменений на зависимости
или переработку lifecycle.

Комментарии runtime-теста ссылаются на roadmap 03.1.1 и объясняют обход и
сохраняющееся ограничение inline-вывода.
Сообщённая регрессия вывода data с вложенными методами обойдена выносом
объекта data перед созданием сигнала: типы аргументов методов выводятся без
cast или явных generics. Удалены устаревшие подавления TypeScript из runtime
случая. Строгие fixtures проверяют data конструктора/фабрики и доступ к методам
через полный self, включая неверные аргументы. Inline-форма в этом случае
остаётся неподдержанной; roadmap 03.1.1 фиксирует воспроизведение, альтернативы
и отложенную работу над сигнатурами без заявления об общем исправлении вывода.
