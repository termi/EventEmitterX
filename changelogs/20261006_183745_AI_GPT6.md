EventSignal.ts delegates hooks, rendering, initialization, registration and RAF
subscriptions to EventSignalReact.ts through a typed private-operation bridge.
EventSignalReactScheduler.ts contains the existing callback pool. Public generic
contracts, stable callbacks and the null-rooted prototype remain intact. Core
shrinks from 4406 to about 3440 lines. The adapter imports the core only as a type.

Two complete-rename branches and a merge establish ancestry before extraction.
Added five React integration tests and strict hook/component-prop type assertions.
The five tests also pass against the original main source. EventSignal: 108 passed,
1 skipped; emitted declarations pass in all three modes with the unchanged 36
library diagnostics. Full suite: 391 passed, the same 14 events_spec failures,
1 skipped, 6 todo. No queue/lifecycle behavior or dependency packages were changed.
