- `state/requestData.ts` exports the `Album` shape and a pure `searchAlbums` matcher. Matching trims queries and searches case-insensitive title/artist substrings and year strings. Both asynchronous paths keep their existing delay and error mechanisms.
- Presets update both search inputs and disable random errors to demonstrate successful results. Explicit `error` input still exercises synthetic failures; the existing render-test routine restores random-error mode when finished. ## [RU] Технические подробности

- CSS clicker использует общие переменные темы и отдельное оформление карточки шаблонного счётчика, исключая конфликт глобальных стилей карточек. Навигация использует `NavLink` с точным совпадением корневого маршрута. Нативные подписи, стили фокуса и поддержка reduced-motion улучшают взаимодействие.
- Крупная игровая кнопка сохраняет исходный обработчик и dataset раунда; нативная семантика добавляет клавиатурную активацию. Выбор раунда отдельно поддерживает Enter/Space.
- `pages/examples.module.css` задаёт оформление страниц лаборатории. Неиспользуемый `3.three.module.css` удалён. Метаданные страниц используют существующий двуязычный механизм `i18n$$`; текст пустого состояния виджетов подписывается на смену языка через кешированный сигнал.
- `AlbumResults.tsx` и его CSS-модуль обеспечивают общее представление результатов React Suspense и EventSignal без объединения их асинхронного состояния или кешей. Иллюстрации создаются локальным CSS, а не загружаются как обложки альбомов.
- `state/requestData.ts` экспортирует структуру `Album` и чистую функцию поиска `searchAlbums`. Поиск обрезает пробелы и проверяет подстроки названия/исполнителя без учёта регистра и строковое представление года. Оба асинхронных варианта сохраняют существующие механизмы задержки и ошибок.
- Кнопки примеров обновляют оба поля поиска и отключают случайные ошибки для демонстрации успешного результата. Явный ввод `error` по-прежнему демонстрирует синтетические ошибки; существующая процедура проверки рендеров восстанавливает режим случайных ошибок после завершения. Поэтому примеры меняют текущий сценарий, а не только видимый текст.
