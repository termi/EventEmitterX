# 08 — Подготовка и выпуск npm-релиза

Приоритет P0. Фактическая публикация — отдельное действие после готового проверяемого состава и выбора владельцем. Этот
аудит не публикует пакеты.

## Проверяемый релизный состав

- [ ] P0 issues AUDIT закрыты или исключены из явно выбранного экспериментального состава; известная утечка не скрыта
  документацией про destructor.
- [ ] RunEnv/type_guards/abortable и другие обязательные зависимости проверены; имена, версии, лицензии,
  README/repository/homepage и access подготовлены.
- [ ] Свежая сборка даёт декларации без ошибок и повторяемый manifest/file list. Локальный дистрибутив не заменяет clean
  rebuild.
- [ ] Сохранены SHA/revision, версии toolchain, changelog, размер и checksum каждого tarball, итог matrix тестов.
  Tarball fixtures устанавливаются без links/dev patches.
- [ ] npm pack просмотрен на точные exports/files, установку без scripts, отсутствие локальных путей, лишних
  demos/caches и случайных данных.
- [ ] Обязательные CI проходят на выбранных минимальных/актуальных версиях. Public types проверяются в поддерживаемых
  режимах TS и реальные React fixtures проходят.
- [ ] Migration notes описывают old deep paths, alias EventEmitter, type fixes, map/async поведение и lifecycle. Номер
  версии соответствует выбранному контракту; не менять версию в ходе аудита.
- [ ] Подготовлен порядок публикации из графа: зависимости → основная библиотека; dist-tag и release scope представлены
  владельцу конкретно.
- [ ] После публикации проверить install уже из registry в clean consumer, сверить tarball identity и ссылки
  документации. План дефектного релиза: новый исправляющий выпуск и deprecation/уведомление по необходимости, без
  обещания безусловного unpublish.

## Завершение

Владелец получил конкретные имена/версии/tarballs и результаты проверок. Публикация выполнена только в рамках отдельно
выбранного действия и подтверждена registry smoke test. До этого состояние этапа — «подготовлен», а не «опубликован».
