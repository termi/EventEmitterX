## Исправленная база реализована — 2026-10-07

обе development-сборки, потребителей/выполнение output и нативный/fallback GC отдельными шагами.
14 падений и 36 диагностик библиотеки устранены без отключения тестов или строгих настроек.

- Библиотека/source-контракты: ноль диагностик; потребители declarations проходят CommonJS, NodeNext и Bundler без skipLibCheck.
- Runtime: 429 pass, ноль падений, один исходный skip и шесть исходных todo; 14 новых точечных Node/DOM-тестов.
- CJS/ESM-сборки включают авторские `.d.ts`; последовательные и параллельные команды проходят. Настоящий CJS runtime smoke проходит.
- GC сигналов и fallback явного dispose проходят; глобальные каналы со слабыми callbacks остаются активными.

## 01.1 — Реализованная инфраструктура команд

Следующая таблица сохраняет исторический снимок 01.1. Её падения исправлены описанным выше изменением.
Область компиляции остаётся ограниченной библиотекой; остальные задачи этапа открыты.

| Команда                      | Назначение                                             | Наблюдаемый результат                             |
|------------------------------|--------------------------------------------------------|---------------------------------------------------|
| `pnpm test --runInBand --ci` | Существующий набор Jest и его конфигурация             | 352 passed, 14 failed, 1 skipped, 6 todo; exit 1  |
| `pnpm run typecheck`         | Проверка только библиотеки через tsconfig.library.json | 36 диагностик, без demo; exit 2                   |
| `pnpm run build:cjs`         | Development output CommonJS в build_ts/cjs             | Выводятся диагностики компилятора; ненулевой exit |
| `pnpm run build:esm`         | Development output модулей ES2020 в build_ts/esm       | Выводятся диагностики компилятора; ненулевой exit |
| `pnpm run build`             | Последовательная CJS/ESM-сборка через pnpm             | Останавливается на первой неуспешной сборке       |
| `pnpm run build:parallel`    | Оба процесса компилятора с общим exit status           | Обе ошибки отражены; exit 1                       |

Все три конфигурации выбирают одинаковые 13 корневых файлов библиотеки под modules/ и utils/. Общая конфигурация
наследует существующие строгие настройки, ограничивает ambient types значением node и исключает
demo/spec/spec_utils/packages/_dev и output-каталоги. Декларации зависимостей всё ещё могут загружаться для разрешения
импортов; exclude не запрещает dependency resolution. noEmitOnError не позволяет записывать частичные артефакты:
обе проверки emit через compiler API пропустили генерацию и выполнили ноль записей. Существующие исходники,
настройки Jest и каталоги пакетов не изменены.

Development ESM-сборка выпускает .js; это не итоговая .mjs-поставка и не проверенная Node package entry.
Root exports, переписывание расширений, проверка чистого потребителя и публикация остаются задачами этапа 06.
Поля версий devEngines используют `*`, чтобы существующие требования Node/pnpm были синтаксически применимы без
преждевременного выбора поддерживаемого диапазона; закрепление toolchain остаётся задачей 01.5. Требование pnpm сохранено.

При проверке автоустановка зависимостей bundled pnpm была выключена через
`pnpm_config_verify_deps_before_run=false`, чтобы использовать установленные зависимости без изменения.
Для доступа sandbox к node_modules потребовалось расширенное разрешение выполнения. Это окруженческое переопределение
не добавлено в настройки проекта. Логи остаются в игнорируемом build_cache/roadmap-01-1/.
Результаты относятся к проверке 2026-10-06.
